# Go in One Evening

Exercises and solutions from the **[Go in One Evening](https://threedots.tech/go-in-one-evening/)** interactive course by [Three Dots Labs](https://threedots.tech/).

## Course Curriculum & Topics Covered

- **Getting Started:** `main` package, imports, `fmt` package, and basic program execution
- **Functions & Variables:** Function signatures, multiple return values, variable declarations, and basic types
- **Control Flow:** Conditionals (`if`/`else`), `switch` statements, and `for` loops
- **Data Structures:**
  - **Slices:** Creation, appending, slicing, and iterating with `range`
  - **Maps:** Key-value storage, lookups, and deleting elements
  - **Structs:** Custom types, struct fields, and methods
- **Pointers:** Memory addresses (`&`), dereferencing (`*`), and pass-by-value vs. pass-by-reference
- **Interfaces & Errors:** Implicit interfaces, the built-in `error` interface, and idiomatic error handling
- **Standard Library & Practical Go:** Working with packages, HTTP servers/clients (`net/http`), JSON encoding/decoding, and testing
